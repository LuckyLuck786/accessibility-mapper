# Ghost Space - deployed Python bundle (Vercel function)
#
# Kept deliberately small. Vercel caps a Python function bundle at ~250 MB, so:
#   * ultralytics / torch are NOT here (the ~900 MB detector). Classification
#     runs behind the `BarrierClassifier` interface and uses the built-in
#     heuristic by default; point CV_ENDPOINT_URL at your own inference service
#     to use a real model.
#   * GeoAlchemy2 / shapely are NOT here. Columns are plain lat/lng floats and
#     every proximity query is haversine in Python. PostGIS is optional and only
#     adds DDL, never a Python dependency.
#   * uvicorn is NOT here: Vercel runs the ASGI app itself.
# ---------------------------------------------------------------------------
